# design-portfolio

Portfolio site of Anastasia Aleksandrovskaia, a graphic designer based in Belgrade.
Built with [Astro](https://astro.build) and hosted on Cloudflare Pages.

**[anastasia-design.pages.dev](https://anastasia-design.pages.dev)**

![Site preview](public/og-image.jpg)

## Development

```sh
pnpm install
pnpm dev
pnpm build
```

Projects live in `src/content/projects/`, images in `src/assets/projects/`.
